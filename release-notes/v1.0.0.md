## LED Pattern Studio 1.0.0

Erste Version als Mac-App.

- Patterns für die 64 × 48 LED-Wände mit Live-Vorschau erstellen: 12 Ebenentypen, Farben,
  Bewegung, Beat-Hüllkurven, Zeichnen-Werkzeuge, 16 Vorlagen
- BPM-Vorschau mit Tap-Tempo und Metronom, Prüfung auf nahtlose Loops
- Export aller Patterns als `.lwb`-Bank für den Pico 2W
- **Updates direkt in der App** (Menü „LED Pattern Studio → Nach Updates suchen …“)
