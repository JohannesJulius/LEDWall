          Ausgewählte Wand

          Export für die Wand

          Alle Patterns werden auf eine Referenz-BPM gerendert und nach Beat-Position abgelegt. Der Pico 2W bestimmt beim Abspielen die echte Geschwindigkeit: frame = floor(beat · framesPerBeat) mod frameCount.

          Projekteinstellungen

          Eine kleine Wand hat 64 × 48 Pixel. Zeichnungen werden beim Ändern der Größe beschnitten bzw. aufgefüllt.
